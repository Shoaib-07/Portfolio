# 🌐 Personal Portfolio Website

## 📌 Overview

This is a **personal portfolio website** showcasing my skills, projects, and achievements in the field of **Computer Science and Web Development**.

The website is designed to provide a clean and interactive user experience, highlighting my technical expertise and project work.

---

## 🎯 Features

* 🧑‍💻 About Me section
* 🛠️ Skills showcase
* 📂 Projects section with live previews
* 📱 Fully responsive design
* ✨ Smooth animations and transitions
* 🔗 Social media links integration

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Responsive Design (Flexbox / Grid)
